# 🎓 Student Companion App (Founder Prototype)

This repository contains the **founder-stage prototype** of a university student companion application.

The goal of this project is to provide students with a **single, unified app** that centralizes academic and campus services normally spread across multiple platforms (Intranet, Blackboard, emails, PDFs, etc.).

The app is designed as a **B2B product for universities**, with students as end users.

### How this differs from aivancity-hub

[aivancity-hub](https://github.com/assim-ben-ahmed/aivancity-hub) is a **hackathon build** for one school: Express + vanilla JS, wired to live Aivancity services (Blackboard/Aimara scraping, Mistral chatbots, Office 365 room-booking emails). This repo is the **founder-stage B2B prototype** of the same idea, a multi-university, white-label product with a Next.js frontend and a TypeScript/Express/Prisma backend, built mock-first so real university APIs can be plugged in later.

## 🚀 Key Features

- 📅 Centralized timetable & daily schedule
- 📚 Courses, assignments, and grades (LMS integration)
- 🔔 Smart notifications & announcements
- 💬 Messaging & student interactions
- 🎓 BDE / student life integration
- 🧠 AI-powered assistants (planning, campus help, productivity)
- 🛠️ Student tools (GPA calculator, room booking, printing, map)
